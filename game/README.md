# НОРМА: браузерный прототип

Игра по мотивам «Колымских рассказов». Один день бригады: поверка, пайка, марш, работа, баланда, барак. Игрок один из восьми, смерть не конец игры: на твоё место встаёт следующий номер, а счёт дней идёт дальше.

## Запуск

```bash
python3 game/tools/serve.py
```

Откроется `http://localhost:8765/game/index.html`. Сервер отдаёт файлы без кэша. Игра берёт графику из `../assets-webp/`, поэтому запускать надо из корня проекта (`/Users/evgen/MyGame1`).

Параметры адреса:
- `?seed=123` — фиксированный мир (бригада, погода, события одинаковые).
- `?autostart` — без титула и вступления.
- `?debug` — числа рядом со шкалами.

## Управление

Мышь или клавиши `1`–`4` для выбора, `Пробел` или `Enter` — «Далее», `Tab` — бригада, `L` — книга учёта, `M` — звук, `Esc` — пауза.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `js/state.js` | Мир и правила: показатели, холод, смерть, смена бригады. Без DOM. |
| `js/events.js` | Колода событий, двусторонние «указы» и 3 особых ветки (актировка, карцер, добавка срока). |
| `js/game.js` | Дневной цикл и шаги выбора. Говорит с игроком только через объект `io`. |
| `js/ui.js` | Панель выбора, карточка события, HUD, экраны дня и смерти. |
| `js/render.js` | Сцены на canvas: слои, спрайты, снег, зерно, виньетки голода и холода. |
| `js/audio.js` | Звук целиком синтезируется (ветер, гул, рельс, шаги, кирка, сердце), музыки нет. |
| `js/assets.js` | Загрузка картинок и атласов. Картинки событий грузятся по требованию. |
| `img/` | Нарезанные кадры и иконки (получены скриптом `tools/slice_assets.py`). |

Книга учёта хранится в `localStorage` (`norma-ledger-v1`).

## Инструменты

Логика отделена от интерфейса, поэтому её можно гонять без браузера:

```bash
node game/tools/simulate.mjs    # баланс: сколько живёт бот (случайный и «разумный»)
node game/tools/coverage.mjs    # все ли выборы событий хоть раз сработали и не падают
node game/tools/trace.mjs       # по шагам, как меняются показатели за 9 дней
python3 -I game/tools/slice_assets.py   # пересобрать img/ из assets-webp/
python3 -I game/tools/slice_dog.py лист.png   # подключить собак (лист 2x2, см. ниже)
```

Последний прогон `simulate.mjs` (150 миров по 80 дней): «разумный» бот в первой жизни живёт около 20 дней, в следующих около 5; случайный около 3.

### Давление барака

У печи есть общий запас топлива: он виден в HUD и тратится каждую ночь. Иногда во время работы возникает короткий двухсторонний указ — спрятать дрова для барака ценой нормы и риска или сдать всё на склад. Второй тип указа заставляет выбрать между лишним уроком для себя и недовыполнением всей бригады. Это не случайные бонусы: решения меняют уже существующие тепло, здоровье, норму, пайку и доверие.

### Новый старт

Обычная новая партия начинает не одним и тем же сценарием: случайно выбираются первая работа (прииск, лесоповал или дорога) и один из четырёх раскладов у ворот. На прииске шесть рабочих узлов в каждой смене тоже перемешиваются. Параметр `?seed=` сохраняет повторяемость мира для отладки.

### Прииск

Шесть часов на прииске — это последовательность разных рабочих узлов: забой, заклинившая вагонетка, трещина в кровле, сортировка породы, усталость смены и последний вагон. Каждый узел меняет цену решения: можно вытащить норму за счёт здоровья, потерять груз ради людей, рисковать наказанием или поддержать слабого. На лесоповале и дороге остаётся общий цикл темпа.

### Литературные мотивы новых событий

Новые бытовые сцены написаны заново, но опираются на ситуации из [«По снегу»](https://shalamov.ru/library/2/1.html), [«Дождя»](https://shalamov.ru/library/2/7.html), [«Сухим пайком»](https://shalamov.ru/library/2/9.html), [«Ягод»](https://shalamov.ru/library/2/12.html), [«Хлеба»](https://shalamov.ru/library/2/17.html) и [«Заклинателя змей»](https://shalamov.ru/library/2/18.html). В игру не перенесены дословные фрагменты и персонажи: это самостоятельные ситуации для системы выбора.

### Редкая записка

После четвёртого дня на марше или ночью может попасться «Записка». Находка не даёт предметов и не содержит произведений Шаламова: она показывает один из коротких оригинальных внутриигровых листков. Для неё используются `assets-webp/p4/04-gloved-hand-note.webp`, `01-found-note.webp` и `02-note-reading-page.webp`; `03-paper-scraps-sheet.webp` оставлен для будущей фоновой анимации.

## Звук

Всё синтезируется в `js/audio.js`, файлов нет. Что слышно:
- кнопки: металлическая пластина (выбор), шорох бумаги («Далее»);
- речь без слов: пока появляется текст, на каждое слово звучит слог. Рассказчик ровный, конвой, повар и десятник грубее, донос и шёпот дыхание;
- удары по герою (глухой удар, хлопок ткани, выдох), выстрел при побеге, лязг карцера, штамп на «добавке» и актировке;
- гул толпы на поверке и в столовой, работа по месту (кирки на прииске, пила и топор на лесоповале, лопата на дороге), черпак, ложки и разлив в столовой;
- барак: треск печи, шёпот, храп, кашель; шаги по снегу на марше; собачий лай вдали и вблизи;
- последствия выбора: хруст при еде, шорох при находке, дрожь от холода, низкий гул при потере рассудка;
- эхо: в бараке и столовой звук идёт через «комнату», на улице почти сухой.

Громкость отдельных звуков правится числами `g:` в соответствующих методах `audio.js`. Звук включается после первого клика (правило браузера). Я проверял его только машинно: все звуки отрабатывают без ошибок и дают сигнал без перегруза. На слух не слушал.

## Подсказки

- **В тексте.** Ключевые слова подсвечены своим цветом, как в «Undertale»: янтарный (хлеб, пайка, махорка, одежда, числа, норма), ледяной голубой (мороз, метель, снег), ржавый красный (удар, смерть, собака, карцер, голод, болезни), зелёный (конвой, бригадир, повар и другие люди). Списки основ слов в начале `js/ui.js` (`KW`), расширять можно там.
- **Над иконками.** Если навести мышь на тепло, сытость, силы, здоровье, рассудок, болезни, хлеб, махорку, день или номер, появляется окошко в стиле книги: бумага, двойная рамка, засечный шрифт, сухое пояснение и строка «Сейчас: …» словами, без чисел. Тексты в `TIPS` в `js/ui.js`.

## Шрифт

Повествование и крупные надписи набраны PT Serif (кириллическая антиква, близкая по духу к книжным гарнитурам советских изданий): `fonts/PTSerif-*.ttf`, достаны из системной коллекции скриптом `tools/extract_font.py`. Документальные детали (заголовки-кикеры, HUD, книга учёта) остались машинописными (Courier New). Поверх текста лежит SVG-фильтр `#ink` (в `index.html`): неровный край букв и пятна недокраса, как на дешёвой типографской бумаге. Отключить эффект: убрать `filter: url(#ink)` в `style.css`. PT Serif © ParaType, распространяется по лицензии ParaType Free Font; если будешь выпускать игру публично, проверь условия лицензии.

## Собаки

Лист конвойной собаки подключён: `sprites/characters/guard-dog-poses.png` содержит 2 × 2 ячейки на ровном фоне — сверху ходьба влево/вправо, снизу сидение влево/вправо. Скрипт `slice_dog.py` уже создал runtime-кадры для марша, поверки и работы.

## Что не проверено и не сделано

- Звук проверен только на отсутствие ошибок, на слух не слушал.
- Раскладка рассчитана на широкий экран 16:9, телефонов нет.
- Нет мини-игры работы (час решается выбором темпа), нет арта для блатного, доносчика, фельдшера и повара в самих сценах: они есть только на карточках событий.
- Вес `assets-webp/` 48 МБ. При старте грузится около 17 МБ (фоны, слои, оверлеи, спрайты), картинки событий подтягиваются по требованию.
