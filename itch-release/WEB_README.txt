NORMA - CAMP SPRITE PACK (WebP edition)
=======================================

Browser-ready WebP version of the NORMA art, exactly the files used by the web
prototype, with their original folder layout and JSON atlas data. Nothing is
re-encoded: these are the original WebP files.

For the same art as lossless PNG with clean English folder names, individual
frames and extras, download the Complete PNG pack.

Folders (original layout)
  atlas/        256 px character and item atlases + JSON  (atlas_cells/ = single cells)
  events/       7 event illustrations
  interface/    ledger pages, logo, number patch, stamps, mark tag
  overlays/     snow, frost, film grain, old paper
  parallax/     march panorama 3840x1080 + mid layer + JSON
  p1/           prisoners, UI, backgrounds (yard, mine, forest, road layers), particles, overlays
  p2/           characters, events, items, locations
  p3..p10/      logo texture, cursor, notes, portraits, story illustrations, playing cards
  *.webp        11 full scenes (1920x1080)

Note: atlas/guard-dog-256.* and atlas_cells/guard-dog-256 are black silhouette drafts.

All images were produced with generative AI tools and then cut, cleaned and packaged
with scripts. Please read LICENSE.txt before use.
