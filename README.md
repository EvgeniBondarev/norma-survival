# НОРМА

Небольшая браузерная survival-игра о лагерном быте, одиночестве и последствиях решений. Это не игра о построении команды: приказы приходят извне, вещи делают человека заметнее, а последствия часто становятся ясны только спустя несколько дней.

## Играть

После публикации: <https://evgenibondarev.github.io/norma-survival/game/>

## Что есть в игре

- смены, мороз, голод, болезни, долг и лагерная «память»;
- приказы, обыски, отсроченные отметки и непрозрачные последствия;
- ночные действия в бараке, включая «очко» и «дурака» с самодельной колодой из 36 карт;
- иллюстрации, портреты, интерфейс и звук в единой книжной графике;
- случайные, но воспроизводимые прохождения по seed-параметру.

## Локальный запуск

Проект не требует Node.js или сборки. Нужен Python 3:

```bash
cd MyGame1
python3 game/tools/serve.py
```

Откройте <http://localhost:8765/game/>.

Для воспроизводимого старта можно добавить параметры, например:

```text
http://localhost:8765/game/?autostart&seed=123
```

## Проверки

```bash
node game/tools/coverage.mjs
node game/tools/determinism.mjs
node game/tools/simulate.mjs
```

## Структура

- `game/` — игровой клиент и диагностические скрипты;
- `assets-webp/` — оптимизированные ресурсы, которые использует браузер;
- `sprites/` — исходные PNG, промты и рабочие иллюстрации;
- `reports/` — заметки об игровых мотивах.

## GitHub Pages

Публикация настраивается автоматически через GitHub Actions. Каждый push в `main`, меняющий игру или её ресурсы, разворачивает содержимое папки `game/` вместе с необходимыми ассетами.

## Источники и тон

Игра опирается на художественную прозу Варлама Шаламова как на источник атмосферы и тем, а не пересказывает произведения буквально. Текст и механики созданы для интерактивной игры.
